# Mi comercio electrónico - Semana 7 (PFY2201)

Aplicación web de comercio electrónico desarrollada con **React** y **Vite**, implementando componentes funcionales modulares, gestión de estado con `useState` y renderizado condicional.

## Funcionalidades
- **Catálogo de productos**: Visualización de nombre, descripción corta, precio normal (tachado), precio de oferta e imagen.
- **Carrito de compras interactivo**:
  - Incrementar unidades (`+`).
  - Decrementar unidades (`-`).
  - Eliminar producto completo (`🗑`).
  - Contador reactivo de productos totales.
  - Cálculo dinámico de la suma a pagar.

## Requisitos
- Node.js (LTS recomendado)
- npm
